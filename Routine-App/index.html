🤖 কোন AI দিয়ে রুটিন বানাবেন তা নির্বাচন করুন। নির্বাচিত AI-এর API Key লাগবে (একবার দিলেই হবে)।
✨ নির্বাচিত AI স্বয়ংক্রিয় রুটিন তৈরি ও ভয়েস কমান্ডের জন্য ব্যবহার হবে।

📋 Gemini API Key পাওয়ার নিয়ম:

  1. aistudio.google.com/app/apikey এ যান
  2. Google account দিয়ে login করুন
  3. "Create API Key" চাপুন
  4. একটা লম্বা code পাবেন (যেমন: AIzaSy...) সেটা copy করুন
  5. নিচে paste করুন

📋 Claude API Key পাওয়ার নিয়ম:

  1. console.anthropic.com/settings/keys এ যান
  2. "Create Key" চাপুন এবং key copy করুন (sk-ant-...)

📋 OpenAI API Key পাওয়ার নিয়ম:

  1. platform.openai.com/api-keys এ যান
  2. "Create new secret key" চাপুন এবং copy করুন (sk-...)

📋 Perplexity API Key পাওয়ার নিয়ম:

  1. perplexity.ai/settings/api এ যান
  2. API Key generate করুন (pplx-...)
⚠️ এই key শুধু আপনার ব্রাউজারে save হবে, কোথাও পাঠানো হবে না।
